# homebrew-tap

Official Homebrew Tap for [Memora](https://github.com/YJoeHadinata/memora) and macOS utilities by [YJoeHadinata](https://github.com/YJoeHadinata).

## Installation

To install Memora:

```bash
brew install --cask YJoeHadinata/tap/memora
```

Or tap the repository first:

```bash
brew tap YJoeHadinata/tap
brew install --cask memora
```

## Update

```bash
brew upgrade --cask memora
```

## Uninstall

```bash
brew uninstall --cask memora
```
